# Technical FAQ / 기술 FAQ

## Resetting your password / 비밀번호 재설정
Go to Settings -> Security -> "Reset password" and follow the email link.
설정 -> 보안 -> "비밀번호 재설정"에서 이메일 링크를 따라가세요.

## Supported file formats / 지원 파일 형식
The app accepts PDF, Markdown (.md), and plain text (.txt).
앱은 PDF, 마크다운(.md), 일반 텍스트(.txt)를 지원합니다.
